Todo lo esencial, dentro del proyecto

La memoria está curada, separada por proyecto y protegida por lifecycle. El runtime no depende de red, proveedores LLM ni servicios remotos.

◈

Memoria con contexto

Sesiones, resúmenes, decisiones, descubrimientos, preferencias, relaciones y actualización idempotente mediante subjectKey.

⌕

Recuperación local

Búsqueda lexical FTS5, briefing compacto, listado de memoria activa y filtros por proyecto, área y lifecycle.

✓

Operación recuperable

Doctor de sólo lectura, backup, upgrade y rollback. Migraciones FTS5 atómicas, WAL y reintentos acotados para concurrencia multiproceso.

↺

Conocimiento corregible

Revisión programada, correcciones con historial y relaciones versionadas. La consolidación requiere vista previa y confirmación explícita.

⌘

Integración por host

Setup y uninstall idempotentes para Codex, Claude Code, Pi y OpenCode. Conservan configuración ajena y no eliminan la base local.

⌁

Distribución verificable

CI en tres plataformas y releases firmados con manifiestos, hashes SHA-256 y firmas Ed25519 antes de publicar.

Las 13 tools MCP

El servidor queda fijado al proyecto configurado. Las consultas son de sólo lectura; las escrituras mantienen los controles del core.

memory_session_start

Abre sesión y devuelve briefing o búsqueda inicial.

memory_search

Busca memoria relevante con una consulta enfocada.

memory_list

Explora memoria activa sin requerir consulta.

memory_timeline

Recorre registros por última actualización, con filtros de fecha.

memory_get

Lee una memoria por ID dentro del proyecto.

memory_save

Guarda o actualiza conocimiento durable.

memory_session_finish

Cierra una sesión y guarda un handoff opcional.

memory_review_list

Encuentra memorias que requieren revisión.

memory_review_complete

Registra una revisión y agenda la próxima.

memory_correct

Crea una corrección sin perder el historial.

memory_relations

Inspecciona relaciones y versiones vinculadas.

memory_consolidation_preview

Previsualiza una consolidación sin escribir.

memory_consolidate

Aplica una consolidación confirmada.
